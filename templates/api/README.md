# __PROJECT_NAME__

Express + TypeScript + TypeORM + PostgreSQL + JWT API, generated by [create-ahad-backend](https://www.npmjs.com/package/create-ahad-backend).

## Getting started

```sh
npm install
createdb __DB_NAME__     # or create the database however you normally do
npm run migration:run
npm run dev
```

The server listens on http://localhost:__PORT__.

## Configuration

`.env` is generated for you, including a random `JWT_SECRET`. Update the database
credentials to match your local PostgreSQL before running the migrations:

| Variable | Description |
| --- | --- |
| `PORT` | Port the HTTP server binds to |
| `DATABASE_HOST` / `DATABASE_PORT` | PostgreSQL location |
| `DATABASE_USER` / `DATABASE_PASSWORD` | PostgreSQL credentials |
| `DATABASE_NAME` | Database to connect to |
| `JWT_SECRET` | Secret used to sign tokens — keep it out of version control |
| `JWT_EXPIRES_IN` | Token lifetime, e.g. `7d` |

Every variable is validated by `src/config/env.ts` at startup, so a missing or
malformed value fails immediately with a message naming the offending variable.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the server with reload on change |
| `npm run build` | Type-check and compile to `dist/` |
| `npm start` | Run the compiled server |
| `npm run migration:run` | Apply pending migrations |
| `npm run migration:generate -- src/migrations/YourName` | Generate a migration from entity changes |
| `npm run migration:revert` | Roll back the last migration |

## API

All responses are JSON: `{ "data": ... }` on success, `{ "error": "..." }` on failure.

| Method | Route | Auth | Description |
| --- | --- | --- | --- |
| `POST` | `/register` | — | Create an account, returns a token |
| `POST` | `/login` | — | Exchange credentials for a token |
| `GET` | `/me` | Bearer | Current user |
| `GET` | `/posts` | — | List posts, paginated via `?page=&limit=` |
| `GET` | `/posts/:id` | — | Single post |
| `POST` | `/posts` | Bearer | Create a post |
| `PUT` | `/posts/:id` | Bearer | Update a post you own |
| `DELETE` | `/posts/:id` | Bearer | Delete a post you own |

Authenticated routes expect an `Authorization: Bearer <token>` header.

```sh
curl -X POST http://localhost:__PORT__/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"password123"}'
```

## Project layout

```
src/
├── index.ts          # app bootstrap
├── data-source.ts    # TypeORM DataSource
├── config/env.ts     # zod-validated environment
├── types/api.ts      # ApiResponse<T>, Paginated<T>
├── errors/           # AppError + typed subclasses
├── middleware/       # auth, error handler, 404
├── utils/            # asyncHandler, jwt, logger
├── migrations/       # one migration per entity
└── modules/          # auth, user, posts — each with routes/controller/schemas
```

## Adding a resource

1. Create `src/modules/<name>/<name>.entity.ts` and register it in `src/data-source.ts`.
2. Add `<name>.schemas.ts` (zod), `<name>.controller.ts`, and `<name>.routes.ts`.
3. Mount the router in `src/index.ts`.
4. Run `npm run migration:generate -- src/migrations/Create<Name>Table`, then `npm run migration:run`.

Controllers wrap handlers in `asyncHandler` and `throw` typed errors
(`NotFoundError`, `ForbiddenError`, ...) — the central error handler maps each to
the right status code, so no `try/catch` is needed per route.
